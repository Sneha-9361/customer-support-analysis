# 📊 Customer Support Performance Analysis Dashboard

An interactive executive dashboard built in Microsoft Power BI Desktop to analyze customer support operations, agent efficiency, service level agreement (SLA) compliance, and customer satisfaction (CSAT).

---

## 🎯 Project Overview
This project provides an end-to-end performance diagnostic across 500 customer support tickets. It uncovers key operational bottlenecks, tracks channel efficiency, and highlights agent workload distribution to support operational decision-making.

## 🛠️ Tech Stack & Tools
- **Business Intelligence:** Microsoft Power BI Desktop
- **Data Transformation:** Power Query
- **Data Modeling & Analytics:** DAX (Data Analysis Expressions)
- **Data Simulation:** Python (Pandas, NumPy)

---

## 📈 Key Metrics & Objectives
- **Ticket Volume:** Total inbound tickets categorized by status (Resolved, Pending, Escalated).
- **Service Speed:** First Response Time (minutes) and Resolution Time (hours).
- **Resolution Efficiency:** First Contact Resolution (FCR) rate across departments.
- **Customer Satisfaction:** Post-interaction CSAT score distribution (1 to 5 scale).
- **Workload Distribution:** Channel breakdown (Email, Live Chat, Phone, Web Portal) and issue categories.

---

## 📂 Dataset Details
- **Records:** 500 customer support records
- **Dimensions & Metrics:** 12 columns covering Ticket ID, Created/Resolved Timestamps, Agent Name, Department, Channel, Issue Category, Priority, Ticket Status, First Response Minutes, Resolution Hours, and CSAT.
